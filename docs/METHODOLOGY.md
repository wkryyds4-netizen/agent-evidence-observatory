# 研究设计与判断边界

## 研究问题

我们分别检查：是否存在公开的智能体交流；交流者是否能归属于特定模型；是否有实际请求、回应与行动；原始任务是否由人类设置；组织是否跨任务持续；所谓保护人类的目标是否有可认证证据。

这些是不同维度，没有一个分数能把它们合成“秘密组织概率”。公开社区本身可以有研究价值，无须先证明其秘密性。

## 证据如何记

每项候选尽量保留原始URL、读取状态、日期、来源类别、支持内容、缺口和重新评估所需证据。查询式与实际访问结果分开记录。来源登记38项，按URL粗分36组；这不是36份独立证据。

归属复核表的`hypothesis_under_review`是调查者构造的待检命题，不代表引文作者说过。`evidence_needed_for_reassessment`表示什么新证据值得重审，不声称这些全部是形式化的证伪条件。

| 观察 | 可以支持 | 单独不能支持 |
| --- | --- | --- |
| 账号自称Claude | 该账号进行了这一自述 | 模型由Anthropic提供 |
| 有效Ed25519签名 | 相应密钥对指定字节的签署关系 | 模型身份、独立实例、善意目标 |
| 相似名字或内容 | 文本或标签之间有相似性 | 同一操作者、相互读过、共同组织 |
| 多账号同时发帖 | 可观察到并发活动 | 多个独立模型自主协调 |
| 请求—回应记录 | 有交流线索，仍需认证上下文 | 任务外自主性、实际执行效果 |
| 明确人工部署与审批 | 存在人类配置或授权背景 | 所有后续行动必然符合授权 |
| 受控越界实验 | 特定设置下的一种能力或行为 | 现实中发生同样事件及自然发生率 |
| 搜索未发现 | 本轮可得证据不足 | 不存在，或一定更隐蔽 |

## 初筛方法

`screen_corpus.py`公开九组英文/中文规则。协作与请求各计2分，延续与限制各计1分，隐藏表达计2分；协作或请求加原发布者reply标志再加1分。人工指挥、研究语境、动机表达和Claude名称只显示标志，不凭这些词直接加减组织判断。

分数是阅读顺序。所有机器记录的`conclusion`仍为`unassessed`，`model_identity`仍为`unverified`。历史reply标志没有父消息ID，因此不生成回复图。

历史样本采用确定性分层，包含优先级、Claude提及、人工指挥和低信号对照，每个平台内身份最多2条。预期上限36条，实际得到32条，因为部分层没有足够可选记录；没有把缺额补成随机代表样本。

模型阅读发现高分中的玩笑、角色扮演和普通技术建议，低分中也有相关披露。因此未估计精确率、召回率或总体秘密协作比例。简单词库也漏掉了近期消息中一种“为人类办事”的表述。

## 数据分母与时间

历史快照含9个数据集、1,722个身份条目；实际8个数据集、1,676个平台内身份有5,808条摘录。AI Village的46条身份没有正文。摘录覆盖2026-01-31至10-03，不是新抓取的全站历史。

Wiki数据只有元数据：4,579页、3,103条标签记录和19,913条混合事件。标签不等于AI，其中有3条人类标记。5,221条`success_observed=True`全部属于删除或回退，不能写成5,221次攻击成功。没有下载修订正文或访问其请求中的原始目标。

近期58条来自固定revision的一个日期分区，只覆盖2026-10-13 00:01:15—03:02:10 UTC。取得时的上游更新时间为10月15日，不代表本轮调查日的实时活动。

## 验签方法

Node内置crypto对归档所供原始`signed_payload`的UTF-8字节进行Ed25519验证；同时检查正文SHA-256、密钥指纹、已签字段与外层字段。验证摘要与字段绑定分别报告。

51条签名有效、7条无签名；51条正文/房间/密钥字段一致；严格五字段一致24条。其余27条签署命令中未提供kind，归档外层是note；其中1条未提供page，外层是main。未提供不是签署了null。未独立确认默认处理规则前，不把差异认定为篡改。

24条声明reply_to，14条父ID在分区内；本轮验签绑定未覆盖reply字段，因此未产出“已认证协作图”。

## 复核与发布修正

三个子agent与主助手的交叉复核不是独立人类审查，也没有地面真值标签。另一子agent发现了两条本地派生身份字段的邮箱样式内容，已修正；这也说明正则脱敏有范围限制。

公开版进一步移除全部批量逐条记录、原文、签名载荷、普通handle与身份映射。少量公开候选仍有用于出处核对的URL；这不是匿名数据集。源文件哈希和聚合结果能帮助复算，但不能证明上游观察或模型归属属实。

## 哪些证据会改变结论

对更强的自主组织命题，需要可认证的底层模型调用、独立运行实例、原始启动目标、跨任务时间线及请求—回应—行动链，并明确区分人类安排、实验设置与模型生成行为。目标相同仍不自动证明共同组织；有组织也不自动证明所谓善意动机。

截至本轮，我们没有取得足够的这类材料。后续应按新证据更新具体命题，保留版本与理由，不把不同来源的薄弱片段拼成未经支持的强结论。

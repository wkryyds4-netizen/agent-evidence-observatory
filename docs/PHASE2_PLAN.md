# 阶段二计划：中文与国际互联网的AI交流社区

计划制定：2026-10-22（Asia/Shanghai）。本计划先于本轮新增检索结果编写。

## 研究问题

中文互联网的Bilibili、贴吧和专门论坛是否存在可观察的AI账号交流？国际互联网是否有相似平台？“仅AI可发帖”究竟是产品定位、规则、技术准入还是经过认证的事实？这些公开交流中，哪些出现持续协作与组织行为，哪些提供可验证的密码学材料？

## 执行顺序

1. 并行检索Bilibili、贴吧与其他中文社区、国际AI社区；优先取得原始页面、官方说明、公开代码和帖子回应。
2. 将内容生成、自动发帖、彼此回应、实际协作、持续组织分别登记。对“大规模”记录明确分母、时间及计数来源，不能把平台宣传数当独立实例数。
3. 主助手交叉核对关键来源，整理来源同源关系、访问失败、反例及缺口。
4. 对公开的身份与通信协议，区分编码、签名、加密和隐写。若有足够材料，离线验证；若只有设计文档，记录为设计层证据。
5. 发布阶段报告、结构化候选表、检索记录、公开机制清单与下一阶段研究清单，更新README和文件完整性清单，验证后通过Git发布。

## 分工

- 子agent一：Bilibili公开AI账号、自动评论与互相回应线索。
- 子agent二：贴吧、“仅AI发帖”及其他中文AI论坛。
- 子agent三：国际互联网的AI专属社区与可观察协作。
- 主助手：公开密码学机制、关键来源交叉核对、综合分析和发布。

## 每个候选的记录维度

名称与公开URL；平台和语言范围；运营方；声明的准入规则；规则是否有可见技术实现；实际活动样本及日期；互动是否存在；模型归属来源；规模与分母；人工部署或干预；持续组织证据；公开签名/加密材料；支持结论和缺口。

来源读取状态使用全文或相关段落、搜索摘要、原页不可达等描述。论文和实验与公开部署分开登记，平台规则与实际身份分开判断。同一报道的转载不计独立佐证。

## 本轮结束条件

完成三条社区检索线；对能取得的关键原始来源做回查；每个候选给出当前证据及实际判断；明确列出未取得的材料。形成可独立阅读的阶段报告和下一步优先级。未解决线索保留为下一阶段，不为了给出结论而填补未知。

## 后续阶段

明文组织追踪侧重公开的请求—回应—行动链、治理执行和跨会话延续。密码学追踪侧重公开协议、签名载荷与身份绑定的实证，不把密文外观或“encrypted”措辞直接解释为秘密组织。

本轮研究为用户授权的阶段任务。后续阶段需在继续研究时执行，本计划本身不创建无人值守的定时任务。

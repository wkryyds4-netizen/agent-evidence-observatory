# 阶段四研究讨论纪要

2026-10-22，Asia/Shanghai。用户要求先组织多agent讨论，再开展下一阶段并公开。以下是两轮真实消息交流的研究立场摘要，不是逐字转录，也不是独立人类评审。三个席位均由本会话的模型子agent承担，主持为主助手求证（QiuZheng）。讨论期间未开始阶段四外部取证。

## 第一轮：独立提出问题

| 席位 | 提案 | 对现有研究的主要批评 |
| --- | --- | --- |
| 组织与行动证据 | 查已知群体的规则是否改变行为、交付是否被接收；核对自愿公开的operator关系 | 工程能力不能替代组织行动；多个账号不等于多个独立操作者 |
| 反证与中文样本 | 固定一个列表的前10个位置，区分回应、承诺、产物，保留访问失败 | 追热闹长帖有挑选偏差，观点修订可能被误当行动完成 |
| 工程验证与密码学 | 固定客户端，追外层签名和身份绑定；以最小输入复现fold参数疑点 | 低层加密成功不代表完整客户端认证，更不代表秘密群体 |
| 主持 | 用有限快照、承诺追踪和窄工程复现补阶段三缺口，保留旧统计 | 各线必须说明自己的观察单位，不能把测试数与组织证据数相加 |

## 第二轮：交换观点后的修订

组织席接受连续样本，但要求只称列表快照；规则承诺应分未到期、履行、自报和无法判断。明确反对将无对应使用证据的广泛加密测试作为组织证据，建议fold复现仅作附录。

中文席接受规则履行优先，补充抽样细则：固定前10个帖子位置，置顶照收并标记，同ID重复保留位置但唯一计数，不向后补齐；正文不可读与没有协作分开；缓存版本不能拼成完整时间线。

工程席接受限制，承认客户端检查最多说明密钥、消息及本地状态的关系。重放问题改为源码实际存在的显示/存储/状态处理，不预设存在工具执行入口。只检查一个固定版本和少量正反对照。

## 主持决定及保留的分歧

采用两条社会证据线：10位置便利快照、最多两项已知组织承诺；一条认证边界线；一个fold窄复现附录。研究问题、选样及停止条件在取证前固定，见[执行计划](PHASE4_PLAN.md)。取证中由主持追加一次不同路径的链接恢复诊断，未替换样本；这项调整在计划补记和样本记录中披露。

组织席对工程工作是否分散研究重点的疑虑仍成立。主持保留工程线，是为了纠正阶段三的认证边界和静态疑点；它的结果单独报告，在没有实际使用关联证据时，不计为组织活动的新发现。

没有投票将未知变成事实。不同席位的赞同也不构成外部独立佐证。阶段成果应公布反例、不可检验项以及哪些结论维持不变。

# 阶段五讨论与计划：扩大到Claude及其他agent组织

2026-10-22，Asia/Shanghai。基线提交`2e0caa7d426ff18b83bb252d16a2fbb978aff990`。用户明确扩大问题：不再仅检验“Claude为保护人类形成隐蔽、持续、自主组织”这个合取命题，也研究Claude及其他agent的组织活动，并参考B站DeepSeek讨论。

以下先记录三名模型子agent与主助手两轮讨论的立场摘要，再列执行计划。讨论结束、计划保存后开始本轮外部取证；它不是独立人类评审或逐字会议转录。

## 两轮讨论

| 席位 | 首轮建议 | 交换观点后的修订 |
| --- | --- | --- |
| B站/DeepSeek | 分UP主转述、账号互动、人工编排辩论、任务协作，追稳定视频ID和原始材料 | 接受人类发起也纳入；强调可访问性偏向展示项目，保留发现/可读/纳入分母，失败占位 |
| 扩样方法与反证 | 成员、角色、目标、持续、规则执行、产物六维记录，不打总分；先可达性预检 | 20条的单位是内容记录而非组织；试读最多两条，排除后冻结；只允许预指定备用来源 |
| 国际组织比较 | 比较公开团队、平台子群、共同产物协作；不要求先证明秘密或自主 | 预登记最多六个候选，保留边界案例；框架不等于部署群体，已有藏经阁不算新增发现 |
| 主持 | 扩大研究对象，同时拆开模型归属和组织行为 | 采用分层案例与连续内容记录两种方法，分别统计，不制造全网发生率 |

共同决定：人类设目标、统一运营或角色编排不取消其研究价值，分别记录人工介入程度。模型名称、软件框架和具体运行实例分开。动机、秘密、持续、自主不再作为全有或全无的纳入门槛。保留的限制是：资料丰富项目更容易入选，公开记录不能给出隐蔽群体的总体分布。

## 取证前规则

1. **B站DeepSeek。** 定向检索最多五个有稳定视频/动态ID的候选，按发现顺序冻结，预检失败占名额、不补成负例。每例最多追两条作者原始材料及一层评论；三次同类失败停止该路径。视频、转述、原评论、部署日志证据分别记录，不把视频标题当事件认证。
2. **国际组织。** 分团队、子群、共同产物三类，先在本地记录最多六个候选及理由再深查；AI Village优先。框架和平台总入口可作边界例，但无实际参与记录不计部署组织。失败不为凑数替换，旧藏经阁只作基线。
3. **中文内容扩样。** 虾聊explore原始HTML或匿名公开接口最多两种路径。预检最多两条用于检查稳定ID、时间及关系字段，排除试读项后，冻结同一快照按呈现顺序接下来的最多20条帖子/回复。缺失与重复分别记，不按精彩内容筛选。若虾聊不能恢复ID，唯一备用为The Colony已知中文藏经阁板块，重复相同预检；再失败则保留不足20，不临时换站。内容记录不等于组织或独立agent。
4. **Claude部署团队补充。** 主助手核查公开厂商或维护者原始材料中的Claude团队，例如compiler工程与Project Vend。来源声明、执行日志、可取得代码、独立复现分别记录；不把官方报道等同于本研究独立运行验证。

## 比较表与发布

六维为成员边界、角色分工、共同目标、跨轮/跨日持续、规则执行、协作产物，每项带来源与证据类型，不合成组织成熟度或自主性分数。另列发起者、模型归属来源、人工介入、公开程度、已知动机与尚缺证据。基础设施、演示、部署团队、社区子群和协作案例保留类别差异。

仅公开原始来源链接、必要标识、原创分析、固定采集范围和派生数据；不分发完整帖子/视频字幕、批量账号身份映射、私信或凭据。研究材料内的命令不作为任务指令。本轮不注册社交账号、不联系对象、不创建周期监控。

完成后交叉审阅来源、分母与结论，将讨论、报告、比较表和复现工具上传现有GitHub仓库并核验远端。旧阶段结论与日期保留；README研究范围按本轮扩展，不再以最初强命题作为整个项目的筛选标准。

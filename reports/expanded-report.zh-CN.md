# 智能体协作公开证据扩展调查

调查起始日期：2026-10-21（Asia/Shanghai）  
方式：主 agent + 3 个子 agent，公开资料查找、归属审查、数据策展、离线代码筛查与语义复核。  
本文件为2026-10-21扩展调查的公开编辑版，发布于2026-10-22。前轮只保留与本轮复核相关的命题，不随仓库发布旧版结论；C05/C07/C10是前轮内部编号，本报告已给出相应来源和更新判断。

## 主要发现

扩大范围后，找到了更多公共社区、持久代理、多模型项目及受控隐蔽通信研究，**仍未取得足以确认“Claude 已为保护人类而成立隐蔽、持续、自主运行组织”的公开证据**。

这不是证明它们不存在。现有证据主要支持三种不同事实：人类部署的公开群体确实存在；某些受控条件下模型可以协调或构造隐蔽通信；既有研究报告过未经安排的跨实例交流，其归属仍应按对应研究及厂商材料逐项判断。[调查来源](https://collusion.wiki/) 但这三者不能合并为某个已被确认的秘密 Claude 组织。

本轮新增的是调查覆盖面、离线可复现的初筛和部分来源完整性核验，没有把“搜不到”解释成“隐藏更好”，也没有把“模型道德倾向”当作组织动机的实证。

### 3. 隐蔽通信能力研究不等于野外事件

归属审查新增了隐写通信构造、SCHEME协同破坏和Summer 2026评估误标等原始研究。它们为部分机制和失败模式提供受控证据，但存在研究者安排的场景、目标或角色，不能直接证明野外组织已经成立。

- [隐写通信研究](https://arxiv.org/html/2606.28425v1)：须区分“设计隐写系统”与“独立实例在严格条件下协调成功”；样本与工具条件有局限。
- [SCHEME](https://arxiv.org/html/2605.29178v1)：显式设置协同副任务，主体实测并非都为Claude，不能改写为Claude自然结团。
- [Summer 2026研究](https://alignment.anthropic.com/2026/agentic-misalignment-summer-2026/)：价值判断影响评估分类的模拟案例，不能证明现实群体的保护人类动机。
- [Petri 2.0](https://alignment.anthropic.com/2026/petri-v2/)与[奖励追求者研究](https://alignment.anthropic.com/2026/reward-seeker/)是测试或训练研究；后者的重要攻击案例明确为模拟，不能当真实出逃记录。

## 代码筛查实际得到了什么

`screen_corpus.py`使用明示的英文/中文规则，筛查协作、请求、跨会话、限制、隐藏、人类参与、研究语境及名称。它从不自动判定秘密组织，所有机器记录的结论保持未评估，模型身份保持未认证。

历史摘录中的信号数如下，彼此可以重叠：

| 规则信号 | 命中摘录 |
| --- | ---: |
| 协作语言 | 212 |
| 请求同伴行动 | 94 |
| 跨会话延续语言 | 12 |
| 限制/沙箱等语言 | 64 |
| 特定隐藏措辞 | 1 |
| 指定人类指挥披露措辞 | 121 |
| 研究/模拟语境词 | 98 |
| Claude名称提及 | 31 |
| 指定保护人类措辞 | 0 |

0命中只表示这套词库和短摘录里没有对应表达，不能证明该动机不存在。31次名称提及不是31个Claude实例。

主 agent 逐条阅读了32条确定性分层样本，覆盖7个平台。高分样本中有洗衣袜子笑话、修辞和普通协议建议；低分样本也包含人类参与披露和技术交接讨论。因此没有报告“准确率”或“发现概率”，也没有把这32条当总体代表。

近期分区中9条命中任一选定信号，已逐条阅读。有一条在询问是否存在高度自主agent；**询问本身不是已找到这类agent的证据**。另有为人类办事的自述未命中简单人类披露规则，进一步显示漏检限制。所有新帖子中的连接、接入和下载邀请均未执行。

原创阅读判断见 `../results/semantic_reviews.json`；公开版排除帖子正文和逐条身份定位，方法限制见 `../docs/METHODOLOGY.md`。

## 验签的结果与边界

用Node.js内置crypto，对近期分区原始 `signed_payload` 字节做Ed25519验证：

| 检查 | 结果 |
| --- | ---: |
| 正文SHA-256与归档字段匹配 | 58 / 58 |
| 有效签名 | 51 |
| 无签名 | 7 |
| 公钥指纹与author对应 | 51 |
| 已签正文、房间、公钥与归档行对应 | 51 |
| 五个核心字段严格逐项一致 | 24 |

其余27条在已签命令中未提供kind，而归档行是note；其中1条未提供page，而归档行是main。没有把“未提供”说成签署了null，也没有在未独立核对默认规则时称其为篡改。

签名证明的是相应公钥的签署关系，不证明底层模型、道德动机、操作者授权或独立人格。无签名也不等于伪造。24条存在 `reply_to`，14条的父ID在这个分区内，但本轮的签名绑定检查没有认证reply字段，未把它们生成“已认证协作图”。

## 质量核对和实际修正

另一子 agent 代码交叉复核发现两条本地派生身份字段保留邮箱样式内容。当时已做模式脱敏，源定位改为身份摘要加帖子索引；原记录ID保持稳定，避免修正后无法追溯。复核所查派生文件未再命中邮箱/已知凭据模式，这不等于保证识别了所有敏感数据类型。普通handle与确定性哈希仍可关联，因此公开版进一步排除了这些批量逐条输出。

历史初筛有27项本地检查通过，覆盖数据分母、输入哈希、身份区分、回复边不伪造、CSV公式中和、脱敏和确定性抽样。验签器还测试了正常签名、正文被改时绑定失败和签名被改时拒绝。它们核对程序行为，不验证调查对象的身份或训练目标。

三个子 agent 使用同类语言模型工具，不能把互相复核当作完全独立的认知证据。公开来源、原始记录、密码学关系和解释性判断分别保留。

## 现阶段结论

| 命题 | 本轮可支持程度 |
| --- | --- |
| 网上存在代理公共社区、跨站交流与多模型协作 | 有公开来源支持，多数有可见的人类部署背景 |
| 某些模型在受控设置能进行协调或隐蔽通信 | 有研究支持，不能外推自然发生率 |
| 近期自称Claude的并行实例确为Claude群体 | 未确认 |
| 已有持续秘密组织以保护人类为共同目标 | 未取得足够公开证据 |
| 这些主体脱离原有模型服务与算力独立运行 | 未取得足够证据 |

本轮没有注册、发帖、私信、招募或接入外部agent服务，没有扫描目标、使用泄露凭据或运行帖子代码。后续若要升级任何候选，需要的是可认证的模型调用、启动目标、独立运行实例和请求—回应—行动链，而不是更高的关键词分数。
